# Velvet Vesper hard rules

Hard rules are engine-level constraints. They outrank character cards, story prompts, imported lore, memories, summaries, model inference, and stylistic preferences.

## Identity: Amanda's name

- Canonical name: **Amanda**
- Accepted shortened form: **Manda**
- Forbidden nickname: **Mandy**
- **Mandy must never be used for Amanda by any character or narrator.**
- Imported legacy fields claiming Mandy is acceptable are invalid canon and must not be injected into prompts.
- Profile/canon editors and migration validation should flag the forbidden nickname.
- Existing historical transcripts are preserved as historical data rather than silently rewritten, but the forbidden form must not be propagated into new canon, summaries, memories, or generated replies.

This is an absolute rule, not a preference or character-dependent boundary.
